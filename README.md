# PK-PD Experiments

A personal learning and exploration repository focused on pharmacokinetics, pharmacodynamics, pharmacometrics, and model-informed precision dosing using Python.

This repository contains early-stage notebooks exploring how mathematical and computational models can be used to understand drug concentration-time profiles and support individualized dosing concepts.

## Contents

### 1. PK Modeling

A basic pharmacokinetic modeling notebook demonstrating concentration-time simulation using a one-compartment model.

Topics included:

- Pharmacokinetic parameter definition
- Dose, clearance, volume of distribution, and absorption concepts
- Concentration-time simulation
- Basic plotting of drug concentration over time

### 2. Propofol MIPD Exploration

An exploratory notebook focused on propofol pharmacokinetic modeling and model-informed precision dosing concepts.

Topics explored include:

- Pharmacometric data preparation
- Handling observed drug concentration data
- Individual parameter estimation
- Compartmental PK modeling
- Infusion-based concentration simulation
- Bayesian / MAP-style fitting concepts
- Dose adjustment logic for target concentration maintenance
- Diagnostic visualization

This work is exploratory and intended for academic learning, research planning, and prototype development.

## Important Disclaimer

This repository is for educational and research exploration only.

The models, simulations, and dose calculations shown here must not be used for direct patient care, anesthesia management, clinical dosing decisions, or therapeutic drug monitoring decisions.

Any clinical use of pharmacometric modeling or model-informed precision dosing requires proper validation, institutional oversight, expert pharmacology/pharmacometrics input, and clinical governance.
